# Modelo de Adicionais e Personalização do Cardápio

Para suporte completo às variações de pedidos em restaurantes, o modelo de dados de um item do cardápio aceita três tipos de personalização:
1. **Opções de Seleção Única** (ex.: Ponto da carne).
2. **Adicionais de Seleção Múltipla com Custo** (ex.: Bacon +R$ 4,00, Ovo +R$ 2,00).
3. **Observações Livres** (ex.: "Sem pimenta").

Isso garante flexibilidade tanto no autoatendimento do Cliente quanto no lançamento rápido pelo Garçom.
