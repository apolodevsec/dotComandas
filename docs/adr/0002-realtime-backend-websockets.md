# Backend em Tempo Real com Node.js e WebSockets/SSE

Adotamos uma API centralizada em Node.js com comunicação bidirecional em tempo real (WebSockets ou Server-Sent Events). Essa decisão é crítica para garantir que pedidos lançados no celular do Garçom ou pelo Cliente apareçam instantaneamente no KDS da cozinha e no consumo da comanda no Caixa, reduzindo a latência de comunicação operacional no restaurante.
