# Stack Tecnológico: Next.js (Web) e React Native Expo (Mobile)

Para atender os múltiplos papéis do sistema (Cliente, Garçom, Cozinha e Caixa), adotamos **Next.js** para os painéis administrativos/opercionais Web (Caixa e KDS) e **React Native com Expo** para as aplicações móveis (Garçom e Cliente). Essa divisão garante acessibilidade via navegador nos computadores/monitores da cozinha e caixa, e performance nativa fluida em dispositivos móveis.
